# Architecture

Documents here, kept in sync with code. `graph-model.md`, `cypher-queries.md` and `deployment.md` exist; `system-design.md` comes later:

- `graph-model.md`: node labels, relationship types, key properties, diagram (required in the README by the rules)
- `cypher-queries.md`: every Cypher query and graph algorithm the product depends on (required by the rules)
- `deployment.md`: where each piece runs, its configuration, how the graph is loaded, post-deploy checks
- `system-design.md`: components, data flow
